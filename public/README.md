# public/

Static assets served at `/`. The icons here are the SVG/static fallbacks;
Next.js auto-generates higher-quality PNG variants from `src/app/icon.tsx`,
`src/app/apple-icon.tsx`, `src/app/opengraph-image.tsx`, and
`src/app/twitter-image.tsx` at build time.

## Files

| File | Purpose |
| --- | --- |
| `favicon.svg` | Modern-browser favicon (Chrome, Edge, Firefox, Safari 14+). |
| `icon-192.svg` / `icon-512.svg` | PWA install icons referenced by the web manifest. |
| `manifest.webmanifest` | Tells browsers / Android how to install the app. |
| `bdt-logo.png` *(optional)* | Drop the official PNG here and `<BdtLogo>` will render it everywhere automatically. Falls back to an inline SVG approximation otherwise. |
| `robots.txt` | Limits indexing of `/admin` and `/api`. |

## Auto-generated by Next.js

These show up at runtime even though there's no file in `public/`:

| URL | Source | Used by |
| --- | --- | --- |
| `/icon` (32×32 PNG) | `src/app/icon.tsx` | Older clients (legacy Outlook, RSS readers). |
| `/apple-icon` (180×180 PNG) | `src/app/apple-icon.tsx` | iOS Add to Home Screen. |
| `/opengraph-image` (1200×630 PNG) | `src/app/opengraph-image.tsx` | iMessage, Slack, Discord, LinkedIn link previews. |
| `/twitter-image` (1200×630 PNG) | `src/app/twitter-image.tsx` | X / Twitter card. |

## Replacing the auto-generated visuals

If you want the OpenGraph card to use a hand-designed image rather than the
generated one, drop `opengraph-image.png` (or `.jpg`) into `public/` and
delete `src/app/opengraph-image.tsx` — Next.js prefers the static file when
both exist. Same pattern for `apple-icon.png`, `twitter-image.png`, etc.
