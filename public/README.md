# public/

Static assets served at `/`.

- `bdt-logo.png` — official BDT Tour shield. Save the logo here and the
  app's `<BdtLogo>` component will render it everywhere automatically. Until
  it's present, the component falls back to an inline SVG approximation so
  the app stays fully branded.
- `favicon.ico` — optional favicon (referenced from `src/app/layout.tsx`).
